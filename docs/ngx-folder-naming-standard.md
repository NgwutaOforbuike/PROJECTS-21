# NGX Folder Naming Standard

Issuer root folder: `<LEGAL COMPANY NAME> [<TICKER>]`

Year folders: four-digit calendar/reporting year, e.g. `2024`.

Permanent document names: `<YYYY-MM-DD if known> - <Document Type> - <Short Description> - NGX ID <ID>.pdf`.

Do not use hashes as the primary human-facing filename. Keep SHA-256 in the manifest and use it only for integrity/deduplication. Preserve legacy legal names and successor names in the issuer profile and identifier-history files.
