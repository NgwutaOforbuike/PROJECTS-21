# NGX Archive Governance

- Preserve raw primary-source documents unchanged.
- Use verified NGX listing year where available; never treat 1970 placeholder dates as genuine.
- Keep a year-by-year coverage register from listing year through 2026.
- Store individual PDFs permanently; ZIP files are temporary transfer containers only.
- Record gaps, broken NGX links, restatements and duplicate URLs explicitly.
- Separate source documents from derived research, valuation models and transaction-readiness work product.
